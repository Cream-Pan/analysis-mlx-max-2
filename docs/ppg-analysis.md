# PPG解析

## 目的

複数デバイスのHR出力を時刻で対応付け，タスク区間ごとにデバイス間の一致度を比較します．この機能はHR系列の比較であり，生PPG波形からHRを推定し直しません．

## 入力

- `*_HR.csv`を2ファイル以上選択します．各ファイルには`RecvJST`と`HR_BPM`が必要です．
- ログファイルは任意です．使用する場合は`Task_Name`と`Timestamp`を含めます．
- 画面で解析開始オフセットや解析時間を指定できます．解析時間を指定しない場合は，共通して利用できる時間範囲を対象にします．

## 解析手順

1. 入力ファイル間で共通する時刻範囲を求めます．
2. ログがある場合はログの各タスク区間を使用します．ログがない場合は画面指定の時間区間を使います．
3. 全ファイルの組み合わせごとに，一方のHRを他方の記録時刻へ時間補間して比較します．
4. 対応した元データと，1分ごとに平均したHRの両方について誤差を算出します．

## 出力

タスクごとにファイルペア，MAE，RMSE，対応データ数を表示します．1分平均の指標は，1分単位で両系列を平均した後に算出します．

## 注意点

ファイル間の共通時刻範囲に記録がないタスクでは，データ不足となります．比較結果はHR系列間の一致度を示し，どちらのセンサが真値に近いかを示すものではありません．
