# PPG→HR変換

## 目的

生PPGの赤外成分から心拍数（HR）を推定し，HR列を付加したCSVを出力します．

## 入力

生PPGのCSVを1つ選択します．`RecvJST`，`IR_Value`，`RED_Value`，`Accel_X_mg`，`Accel_Y_mg`，`Accel_Z_mg`，`SensorElapsed_ms`を含む形式を想定します．サンプリング周波数は先頭最大1,000サンプルの時刻差から推定し，推定できない場合は100 Hzを使用します．

## HR推定

`IR_Value`を10秒窓，5秒刻みで処理します．各窓にFFTを適用し，0.8～3.0 Hz（48～180 bpm）の候補から心拍周波数を選びます．直前の有効値がある場合は±25 bpmの範囲で追跡し，5秒間推定できない場合は全候補から再探索します．ピーク幅などの条件を満たさない窓は推定失敗として扱います．得られた窓ごとの値をサンプル時刻上に補間し，`HR_BPM`列を生成します．

## 出力

入力データに`HR_BPM`を加えた`*_HR.csv`をダウンロードできます．あわせてIRとREDの全体相関係数を表示し，出力CSVには1秒移動相関も含めます．

## ACCと品質上の注意

この変換処理はHR推定にACCを使いません．ACC列は入力・出力CSVに保持しますが，ACCによる体動除外やHR採否判定はしません．ACCを使ってMotion Artifactを判定する解析は，[PPG＋ACC解析](ppg-acc-analysis.md)です．出力HRは推定値であり，ECGとの照合や波形品質の確認を別途行ってください．
