# MLX評価

## 目的

MLX90632の`Object_C`を体温基準データと比較し，タスク区間ごとの誤差と平均温度を算出します．

## 入力

- `body_temperature.csv`：1列目を体温値，2列目を測定時刻として読み込みます．
- MLX測定ファイル：対応するCSVまたはExcelファイルを選択します．CSVでは設定済みの列位置から`Ambient_C`，`Object_C`，`SensorElapsed_ms`，`RecvJST`を読み込みます．
- ログファイル：任意です．使用する場合は`Task_Name`と`Timestamp`を含めます．

## 解析手順

1. `RecvJST`と`SensorElapsed_ms`からMLX側のサンプル時刻を再構築します．
2. MLX値と体温基準データを時刻で対応付け，基準データの時刻上にMLX値を補間します．
3. ログがある場合は各ログ時刻から次のログ時刻までをタスク区間として集計します．ログがない場合は画面で指定した固定区間を使います．

## 出力

各タスクについて，有効データ数，MAE，RMSE，体温基準の平均，`Object_C`平均，`Ambient_C`平均を表示します．MAEとRMSEは，時刻を対応付けた体温基準値と`Object_C`の差から算出します．

## 注意点

この機能はMLXの出力と体温基準データとの一致度を評価します．センサ値の補正式を推定・適用する機能ではありません．列位置や時刻の意味が想定と異なるファイルは，正しい評価にならない可能性があります．
