# MLX回帰分析

## 目的

MLX計測データの先頭2列を同一の温度軸に表示し，指定した時間ごとに一次回帰式を算出します．各タスク中の温度変化を時間に沿って確認する用途を想定します．

## 入力

- ファイル名が`MLX_`で始まるCSV，XLSX，XLSを1～12個選択します．大文字・小文字は区別しません．
- CSVでは先頭2列，Excelでは各シートの先頭2列を対象にします．列の組み合わせや尺度は固定ですが，グラフ上部のチェックボックスまたは凡例から各列の表示を個別に切り替えられます．非表示の列は回帰式と回帰直線の対象からも外れます．
- 回帰区間を秒で指定します．初期値は10秒で，小数も指定できます．
- または「回帰区間を指定せず，ログのタスクごとに算出する」を選びます．この場合はログファイルが必須です．
- 秒指定モードでは，ログファイルは任意です．使用する場合は`Task_Name`と`Timestamp`を含む`*_log.csv`を1つ指定します．

## 区間分割

秒指定モードでログを指定した場合，ログのStartからEndまでをタスク境界で分け，それぞれのタスク区間の先頭から指定秒数ごとに再分割します．例えば10秒を指定すると，Startから次のログ境界までを10秒区間に分け，次のタスクでも同様に区切ります．タスク境界をまたいで回帰しません．最後に10秒未満の区間が残る場合も，その区間を解析対象にします．

タスクごとモードでは，StartからEndまでのログ区間をタスク境界だけで分け，それぞれのタスク区間全体から回帰式を算出します．

ログを指定しない秒指定モードでは，記録の先頭から末尾までを指定秒数ごとに分けます．時間軸には`RecvJST`と`SensorElapsed_ms`による再構築時刻，または`sampling_time`を使用します．数値の`sampling_time`は秒単位として扱います．区間分割には時間軸を使うため，どちらの時間情報もないファイルは解析できません．

## 出力

選択した各ファイル（Excelの場合は各シート）にグラフを表示します．各区間について，1列目と2列目それぞれの一次回帰式，決定係数`R²`，有効点数`n`をグラフの下に表示します．`n`の直後に傾きの符号を表示し，正は赤色の`＋`，負は青色の`－`，傾きが0の場合は灰色の`0`で示します．回帰直線は元データと異なる色で重ねます．「回帰直線を非表示／表示」ボタンで直線だけを切り替えられます．拡大・縮小，横移動，表示範囲リセット，ログのタスク背景と境界線にも対応します．

日時軸では，回帰式の`x`を各区間開始からの経過分として扱います．そのため傾きの単位は温度単位／分です．`sampling_time`を使う場合は，`x`にその列の数値を使います．有効点が2点未満，または区間内で時間軸が変化しない場合は，式を算出できない理由を表示します．

## 制約と解釈

回帰式は指定区間内の一次傾向を表します．生理的な負担や温度の正確さ，センサの品質を直接判定する指標ではありません．複数ファイル間の比較では，列の意味と温度単位が同じであることを確認してください．一度の解析で作成する区間が20,000を超える場合は，区切り時間を長くしてください．
