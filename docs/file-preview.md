# ファイル内容表示

## 目的

CSVやExcelの内容をグラフで確認する機能です．解析指標の算出やセンサ値の補正は行わず，選択した列の時系列・行方向の変化を表示します．

## 入力

- CSV，XLSX，XLS形式のファイルを選択します．
- Excelファイルでは表示するシートを選択します．
- 必要に応じて，タスク境界表示用のログファイルを追加します．ログには`Task_Name`と`Timestamp`が必要です．

## 表示方法

横軸は`RecvJST`と`SensorElapsed_ms`からの時刻再構築を優先し，次に`sampling_time`列，いずれも利用できない場合は行番号を使います．表示対象の列を選び，拡大・縮小しながら波形を確認できます．グラフ下の専用スクロールバー，またはドラッグ操作で表示時刻を移動し，「表示範囲をリセット」で解析対象全体に戻せます．ログを指定した場合は，PPG脈波解析と同じ背景色のタスク範囲，タスク名，縦の破線境界をグラフに重ねます．

「回帰式を表示」チェックボックスをONにすると，選択中の列に最小二乗法による一次回帰式を表示し，グラフにも破線で回帰直線を重ねます．ログありではタスクごとに回帰し，時刻データの場合はタスク開始からの経過分を`x`として扱います．ログなしではファイル全体で回帰し，時刻データの場合は記録開始からの経過分を`x`として扱います．`sampling_time`または行番号を横軸に使う場合は，その値を`x`として扱います．式と併せて決定係数`R²`と有効点数`n`も表示します．有効点が2点未満，または横軸の値に変化がない区間は回帰できない旨を表示します．

## 出力と制約

グラフをPNGとして保存できます．この機能は内容確認用であり，ログがない場合にタスク区間を推定したり，HRなどの解析指標を計算したりはしません．回帰式は表示列の値と現在の表示尺度に対する傾向を示すものであり，因果関係や信号品質を評価する指標ではありません．
