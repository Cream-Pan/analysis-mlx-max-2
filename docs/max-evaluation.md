# MAX評価

## 目的

ECGを基準としてPPG由来の心拍数を比較し，さらにFin側PPG心拍数と耳側PPG心拍数の差を評価します．

## 入力

- ECG基準CSV：`Timestamp`と`HeartRate_BPM`を含めます．
- PPG心拍数CSV：`RecvJST`と`HR_BPM`を含む`PPG_BPM.csv`と`PPG_fin_BPM.csv`を選択します．
- ログファイル：任意です．使用する場合は`Task_Name`と`Timestamp`を含めます．

## 解析手順

時刻をそろえて共通する記録範囲を求め，ログがある場合はログのタスク境界で分割します．各区間では，ECG心拍数をPPG側の記録時刻へ時間補間して比較します．次の2種類を計算します．

1. ECG基準と`PPG_BPM`の比較
2. `PPG_fin_BPM`と`PPG_BPM`の比較

各比較について，取得時刻で対応付けた全データの誤差と，1分単位に平均した値の誤差を別々に算出します．

## 出力

タスクごとにMAE，RMSE，対応データ数を表示します．「元データ」は対応付けた記録全体，「1分平均」は1分ごとに平均した心拍数同士の比較です．

## 注意点

この機能は入力された心拍数系列同士を比較します．生PPGから心拍数を再推定する機能ではありません．時刻の共通範囲が短い場合や対応データがない区間では，指標が表示されないことがあります．
