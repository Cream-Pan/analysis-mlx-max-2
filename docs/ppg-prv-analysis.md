# PPG脈波解析

## 目的

PPG波形から得た拍動間隔を使ってPRV指標を計算し，タスク中のHRと拍動間隔変動を時間変化として確認します．PPG由来のPRVはECG由来のHRVと区別して解釈します．

## 入力とHRの選択

- `RecvJST`と`IR_Value`を含むCSVを1つ以上選択します．
- ファイル名が`_HR.csv`で終わる場合は，そのファイルの`HR_BPM`をHR表示に使います．それ以外のCSVでは，IR波形からPPG→HR変換を実行します．
- PRV指標は，どちらの形式でもIR波形から検出したピーク間隔を使って計算します．`HR_BPM`列をPRV算出には使いません．
- ログを使う場合は`Task_Name`と`Timestamp`からタスク区間を作ります．ログがない場合は区切り分数，開始オフセット，解析時間を指定します．解析時間が未入力の場合はファイル末尾までを対象とします．

## 30秒窓の解析

各タスクを境界をまたがない30秒窓に分けます．HRは有効な`HR_BPM`の平均として算出します．PRV処理ではIR信号をフィルタし，ピーク間隔（PPI）を検出します．0.4～2.0秒（30～150 bpm）のPPIを有効候補として扱い，次の指標を算出します．

- **RMSSD**：連続する有効PPIの差の二乗平均平方根（ms）
- **SDNN**：有効PPIの標準偏差（ms）
- **pPPI50**：連続する有効PPIの差が50 msを超える割合（%）

無効なPPIをまたいだ差は計算しません．PRV指標の計算には30秒以上の区間が必要です．30秒未満の端数区間はPRV指標の集計対象になりません．

## 品質判定と集計

10秒窓を5秒刻みで評価し，0.5～2.5 Hz帯域における最大ピークについて，ピーク／第2ピーク比の平方根，ピーク／平均パワー比，ピーク／中央値比がすべて2以上となる窓の割合と，有効範囲内にあるPPIの割合から各30秒窓を判定します．両方が90 %以上なら「採用」，両方が80 %以上なら「注意付き採用」，それ以外は「除外」です．この閾値は現行実装の暫定値です．ACCの情報も補助指標として計算しますが，現在の採用・除外判定はACC値を直接の条件にしていません．

グラフには30秒ごとのHR，RMSSD，SDNN，pPPI50を表示します．項目を切り替えて確認でき，ホイール／ピンチで拡大，ドラッグまたは専用スクロールバーで横移動できます．「表示範囲をリセット」で解析対象全体へ戻ります．ログがある場合はタスク背景・タスク名・境界の破線も表示します．ツールチップには時刻，タスク，ファイル，値，品質判定を示します．表にはタスクごとに採用・注意付き採用となった30秒窓の単純平均を示し，対象窓数と指標ごとの有効件数を併記します．品質除外の窓は平均に含めません．

## 注意点

本解析はPPGから拍動時刻を検出したPRV解析です．結果をECG由来HRVと同一視しないでください．現行の表示項目はHR，RMSSD，SDNN，pPPI50であり，LF・HFは30秒窓の出力対象ではありません．
